# Atelier Web Application Testing

Testing documentation created for the Atelier e-commerce web application.

🌐 **Application:** [Atelier Online Store] (https://shoe-store-frontend-five-sable.vercel.app/)

The project focused on manual testing of the main customer and administrator workflows.

Artifacts include:

* Test Plan
* Test Scenarios
* Test Cases
* Requirement Traceability Matrix (RTM)
* Bug Reports
* Chrome DevTools Testing
* Test Summary

Documentation is available through the links below.

## Project Overview

Atelier is an e-commerce application offering shoes, bags and accessories.

The testing covered:

* Product Listing Pages (PLP)
* Product Detail Pages (PDP)
* Registration and Sign In
* User Account
* Shopping Cart
* Checkout Process
* Navigation and Filtering
* Product Availability
* Admin Panel and Product Management

Manual and exploratory testing were supported by Chrome DevTools and API checks.

### Chrome DevTools Testing

Chrome DevTools was used to:

* Inspect API requests and responses
* Verify HTTP status codes
* Monitor Console and Network activity
* Check resource and image loading
* Test offline and slow-network behaviour
* Verify responsive layouts
* Monitor the complete purchase flow
* Perform a basic Lighthouse audit

Lighthouse results:

* Performance: 65
* Accessibility: 95
* Best Practices: 96
* SEO: 91
